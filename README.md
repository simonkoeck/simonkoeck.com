# simonkoeck.com

Source code for [simonkoeck.com](https://simonkoeck.com), my personal website for security writeups, projects, and blog posts.

Built with Astro, MDX, Tailwind CSS, and TypeScript, and deployed to Cloudflare Workers.

## Development

Requires Node.js 22 and pnpm.

```sh
pnpm install
pnpm dev
```

Run `pnpm build` to create a production build. Pushes to `main` are deployed through GitHub Actions.
